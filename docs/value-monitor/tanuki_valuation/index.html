METHODOLOGY

動的WACC（CAPM）

銘柄別β × 市場リスクプレミアムで個別のWACCを算出。高β銘柄ほど厳しく割引される。
WACC = Rf + β × (Rm - Rf)

FCFベース自動判定

直近2年/5年平均の変動係数(CV)が閾値を超えるとrecent_2yrを自動採用。成長企業のFCF急拡大を適切に反映。

3段階DCF

高成長期→移行期→永続成長の3段階で鈍化カーブを表現。銘柄ごとに成熟プロファイルを設定可能。
maturity_config.py

セグメント加重成長率 / 推奨成長率

10-K開示のセグメント別売上構成比×成長率で企業固有のCAGRを算出。FCF CAGRより優先される。セグメント未設定銘柄は推奨成長率（rev CAGR / 業界ベンチマーク / g_fundamentalの中央値 × HypeCoreフェーズ重み付き平均の平均値）をDCFに自動適用。

成長オプション（仮説セグメント）

TAM × 侵入率 × マージン × 確率を割引しV₀への加算項として計上。未実現事業の期待価値を反映。

α 成長期待プレミアム

ROE平均 × 内部留保率から個別成長率を算出しWACC比で質的補正を適用。セクター別上限（mega_tech:1.0 / Technology:0.8 / Healthcare:0.7等）。
α = (ROE × 0.6 / WACC) × 0.7

RICE（投資効率指標）

投資が成長として再生産される質と効率を測定。
RICE = (G × VC_Factor × Q × CF) / WACC
Q=OCF÷(純利益+SBC)、CF=売上成長÷投資強度（1年ラグ）

RPO補正 / BS評価補正

前年比超過の非連続需要分×利益率でPV化。αの外に加算。赤字企業はゼロ。ネットキャッシュ/純負債を1株あたり価値に加算。

TABLE LEGEND — 列・バッジの説明

📊 テーブル列の説明

理論株価 BASE
BASEシナリオ（セグメント加重成長率 × 1.0）で計算した1株あたり本質的価値。WACC=Rm固定（10%）のβなし版。現在株価との差が「乖離率」として表示される。
P_t = V₀ × (1 + α) ÷ 株式数 + RPO_PV ÷ 株式数 + GO_PV ÷ 株式数 + BS補正
理論株価 β込み
銘柄ごとのβを反映したWACCで計算した理論株価。β込みWACCはリスク感応度が高い銘柄ほど低く算出される。BASEとの差がβリスクプレミアムの影響を示す。
WACC_β = Rf(4.3%) + β × (Rm-Rf)(5.7%)
乖離率
（理論株価BASE − 現在株価）÷ 現在株価。プラスなら割安、マイナスなら割高を示す。Koichi式では「Extreme Fear + 乖離率がプラスかつ拡大傾向」が強い買いシグナル。
乖離率 = (理論株価 − 現在株価) / 現在株価
200MA乖離
（現在株価 − 200日移動平均）÷ 200日移動平均。プラスなら200日MAより上（強気トレンド）、マイナスなら下（弱気トレンド）。長期的な水準感の参考値。
200MA乖離 = (現在株価 − 200日MA) / 200日MA
yfinanceから取得。パイプライン実行時点の値。
成長率 BASE G
TANUKIが使用するBASEシナリオの高成長期成長率。セグメント加重成長率（segment_config.py設定値）が優先される。セグメント未設定銘柄は推奨成長率（中央値ベース × HypeCoreフェーズ補正の平均）を自動適用（列末尾に「推奨値・中央値を自動適用」と表示）。RICEのGとして使用される。
Bull = BASE × 1.2 / Bear = BASE × 0.7
WACC
加重平均資本コスト。CAPMで動的計算。高いほど将来FCFが厳しく割引されるため理論株価が低くなる。銘柄別βをbeta_config.jsonで設定。
WACC = Rf + β × (Rm − Rf)   Rf=4.3% / Rm=10%

🔢 指標の説明（α / RICE / Q / CF）

α（アルファ）セクター別上限
成長期待プレミアム。ROE平均から個別の成長率ポテンシャルを推定し、市場期待リターン（Rm=10%）との比率で質的補正を加える。高いほど「ROEが高く成長余力がある」企業。セクター別キャップ（mega_tech=1.0 / Technology=0.8 / Healthcare=0.7 / Utilities=0.5等）。
α = min(sector_cap, ROE_avg × 0.6 / Rm × 0.7)
α=cap（キャップ適用）= 極めて高いROE。例: NVDA（mega_tech=1.0）/ LLY（Healthcare=0.7）
RICE 投資効率指標
Reinvestment & Compounding Efficiency。投資が成長として再生産される質と効率を測定する純粋な投資効率指標。銘柄間の相対比較に使用。高いほど「少ない投資で高い成長を再生産している」。
RICE = (G × VC_Factor × Q × CF) / WACC
G=BASEシナリオ成長率 / VC_Factor=clamp(ROIC/WACC, 0.3, 2.0) / Q=OCF転換効率 / CF=投資再生産効率
RICE/PER 割安・割高スクリーニング
投資効率（RICE）を現在の株価収益率（PER）で割った指標。値が高いほど「投資効率の割にPERが低い＝割安」を示す。赤字企業や極端なPERの銘柄は「—」で表示。
RICE/PER = RICE ÷ PER（trailingPE）
PERはyfinanceのtrailingPEを使用。パイプライン実行時点の値。
Q（OCF/NI）キャッシュ転換効率
営業キャッシュフロー ÷ 純利益の直近3年平均。1.0以上なら会計利益がしっかりキャッシュに変換されている。SBC（株式報酬）が多い企業はQ>1になりやすい。
Q = OCF ÷ (純利益 + SBC)（直近3年平均）
Q<1: キャッシュ化が不十分 / Q>2: 利益以上のキャッシュ創出
CF（投資効率）投資再生産効率
「1単位の投資強度が翌年の売上成長率に何単位変換されたか」を示す。1年ラグで計算（t年の投資 → t+1年の売上成長）。投資強度 = (R&D + CapEx + 販売・マーケティング費) ÷ 売上。
CF = 売上成長率(t+1) ÷ 投資強度(t)　※直近3点平均
投資強度 = (R&D + CapEx + S&M) / Revenue
R&D/CapExが極小でも成長する軽資産型企業はCFが高くなる傾向

🏷️ バッジの説明

2YR
FCFベースに「直近2年平均」を採用。変動係数(CV)が閾値0.5を超えた場合に自動適用。直近のFCF急拡大を反映し、5年平均より高い値になることが多い。
非表示の場合は「5年平均（avg_5yr）」を採用。
SEG
成長率にセグメント加重成長率を採用。10-K開示のセグメント別売上 × Koichi設定成長率の加重平均。FCF CAGRより企業の実態を反映するため最優先される。SEGバッジがない銘柄でも、推奨成長率（rev CAGR・業界ベンチマーク・g_fundamentalの中央値 × HypeCoreフェーズ補正）がDCFに自動適用される場合は「推奨値・中央値を自動適用」と表示される。
segment_config.pyで銘柄ごとに設定。
GO
成長オプション（Growth Option）が設定されている銘柄。現時点では存在しない「仮説セグメント」（例: Sovereign AI、Robotaxi）のTAM × 侵入率 × マージン × 確率を割引してV₀に加算。
segment_config.pyのGROWTH_OPTIONSで銘柄ごとに設定。
KO のように バッジなし
セグメント設定・成長オプション・2年FCF採用のいずれもない銘柄。FCF CAGRまたはデフォルト成長率を使用。

⚠️ 読み方と注意事項

RICEは絶対値ではなく相対比較で使う
RICEは「投資効率の純粋な測定指標」として設計されている。単独では割高・割安を判定できず、銘柄間の相対比較（どの銘柄が効率よく成長を再生産しているか）に使用する。
総合的な割高・割安判定はRICEを含む複数指標の組み合わせで将来設計予定。
理論株価は「本質的価値の推定値」
TANUKIの理論株価はβなし・市場心理独立の本質的価値（Layer 1）を算出している。市場が常にこの価格に収束するわけではなく、あくまで投資判断の参考値として使用する。
RKLB / ONDS / SOUN などの赤字企業
FCFがマイナスの銘柄は調整済みEPSからFCF実力値を推定して計算。推定値と実績値の乖離が大きい場合は信頼性に注意が必要。パイプラインログに警告が出る。
データソース
財務データはSEC EDGAR（10-K/XBRL）から自動取得。株価・β・株式数はyfinance。計算は毎週GitHub Actionsで自動更新される。
KOのみ更新日が古い場合がある（段階的対応中）。
