使い方▼
VERDICT
総合判定。
10x CANDIDATE / PROMISING / WATCH / AVOID の4段階。スコア加重で算出。
DEFICIT
赤字の質。
粗利率・R&D比率・売上成長から「投資中の赤字か、単なる損失か」を判定。
RUNWAY
資金余命。
現金 ÷ 月次バーンレート。12ヶ月未満は赤表示。∞ はバーンなし。
OCF TREND
営業CF推移。
IMPROVING / STABLE / DECLINING。黒字化に向かっているかを示す。
SCORE
0〜100の総合スコア。①赤字品質②生存能力③黒字化パスの加重平均。
▲ 買いシグナル
DEFICIT が QUALITY / GROWTH-INVEST ・ RUNWAY が24M以上 ・ OCF TREND が IMPROVING ・ SCORE 70以上が揃えば注目候補。
▼ 回避シグナル
RUNWAY が12M未満（赤）・ DEFICIT が PURE-LOSS ・ OCF TREND が DECLINING の組み合わせは資金切れリスク大。
