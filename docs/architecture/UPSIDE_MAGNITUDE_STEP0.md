## 結論（先に）

1. **理論株価の割引率は、銘柄に関係なく Rm＝10%固定**（β なし。`core_calculator.py` の `_rm`。β込みの WACC は参考の `intrinsic_value_beta` に出るだけ）。NVDA（β 2.2・β込みWACC 16.9%）・APP・SOFI・SOUN・CRWV のような高β銘柄の上昇余地は、これで大きく出る。割引率を β込みWACC に替えると、**全体の中央値で理論株価 −22.7%、保有の NVDA −65%・APP −69%・SOFI −54%・SOUN −57%**。逆に低β（KO・JNJ・ABBV・HQY）は +137〜180% に上がる。
2. **上昇余地を一番大きくしている前提は、銘柄ごとに最大の効きを数えると 割引率（Rm固定）40銘柄・成長率（アナリスト予想より高い）32銘柄・phase1の年数 2・手書きの成長率 1・5%未満の効きしか無い 7**（82銘柄）。上昇余地が +100% 超の11銘柄は、成長率か割引率のどちらかが主因。
3. **全体は信じすぎるほど膨らんでいない**: 上昇余地の中央値は **−23%**（82銘柄中 +50% 超が22、+100% 超が11、BUY 19）。問題は裾（高成長・高βで上昇余地が大きい銘柄）で、全体に上乗せがあるわけではない。
4. **手書きの成長率25銘柄を recommended_g に置き換えると、理論株価は下がらず上がる**（25銘柄の中央値 +10.5%、平均 +17.6%。+10%超が13、−10%超が1〈TER −46%〉）。手書きの値は過去の数字の平均（recommended_g）より低めに置かれている銘柄が多い。置き換えは膨らみの対策にならない。期限・印のほうが合う。
5. **上昇余地がプラスの銘柄では、市場が織り込んだ成長率（逆算）はTANUKIの成長率より低い**: 79銘柄で逆算でき、上昇余地がプラスの28銘柄では TANUKI が逆算より **中央値 +11.3pt 高く**（平均 +15.3pt）、5pt超の差が24・10pt超が19。アナリスト予想（次の会計年度）との差も中央値 +8.2pt（5pt超 18・10pt超 8）。上昇余地がマイナスの51銘柄は逆向き（TANUKI が逆算より中央値 21.4pt 低い。株価が理論株価より高いので当然）。NVDA は市場の織り込み 5.2%・TANUKI 50%（上限）・アナリスト 71%、PAYS は −4.5%・30.2%・12.7%、INTU は −1.1%・12.8%・8.0%。ただし逆算は、割引率 Rm 10%・phase1の年数・ターミナルなど**ほかの前提を今のまま**にした値で、前提が膨らんでいるほど逆算の成長率は低く出る（結論1と同じ向き）。
6. **ターミナル成長率は問題でない**: 全82銘柄が 2.0〜3.5%（無リスク金利 4.3% 未満）。基準の「無リスク金利以下」は既に満たされていて、変わらない（変更0）。参考に −1pt すると全体で −10%（均一）。
7. 案は **表示（信じすぎない形）を先に、計算の変更は割引率・phase1の年数の2つを候補に、決めてもらう**（§6）。

## 6. 案（決めてほしいことを付ける）

### 6-1. 手書きの成長率の25銘柄

- **recommended_g への置き換えは勧めない**: 置き換えると25銘柄の理論株価は中央値 +10.5% 上がる（AVAV +100%・HEI +68%・CELH +66%・GOOGL +53%。下がるのは TER −46% だけ）。手書きのほうが保守的な銘柄が多い。膨らみの対策にならず、判定も動く（CELH WATCH→BUY・VRT HOLD→WATCH）。
- 勧め: **期限を付ける＋古さの印**（`config/segment_config.json` の `fiscal_year` が FY2025、最後の更新が 2026-04-29〜09-05。例: 更新から180日を過ぎたら stock.html と TANUKI SCORE に「手書きの成長率は〇か月前の設定」と表示）。値は変えない（表示だけ）。recommended_g との差は参考の列に出す。
- 決めてほしいこと: (a) 置き換えない（印のみ）でよいか。期限は180日か。(b) 手書きの更新を決算ごとの作業に入れるか（案2〈会社の見通しの手記録〉は不採用の決定のため、設定の更新だけ）。

## 7. この文書の限界

- 前提を**1つずつ**替えた試算で、組み合わせの効果（割引率と成長率の両方など）は足し合わせられない。
- アナリストの売上予想の伸び（次の会計年度）は、会計年度のずれ・買収・取得の揺れがある（`GUIDANCE_REVISION_STEP0.md` §6）。成長率→予想の変種で予想のほうが高い銘柄（CRWV・SITM・AMD など）は、理論株価が上がる向きになる。
- 逆算は他の前提を今のままにした値（上のとおり）。3銘柄（ASTS・RCAT・TSLA）は解けない。
- 試算は2026-11-25のデータ・株価。株価が動けば上昇余地は変わる。
- 判定は `tanuki_score`（funda と timing で決まる）の変化で、HypeCore の stage との読み合い（chain）は含まない。
- hook・集計の道具は scratchpad（`variants.py`・`an1.py`・`an2.py`・`mkdoc.py`）。再現は `tools/sim/sim.py run NAME --hook variants.py`（環境変数 UPS_VARIANT）。
