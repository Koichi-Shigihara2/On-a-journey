## 結論（先に）

1. **成長率に、先の見通しが入る経路は無い。** 理論株価の成長率は (a) 手で書いた設定（`config/segment_config.json`、会計年度 FY2025 のセグメント別の重みと成長率）か、(b) 過去の数字の重み付き平均（直近12か月の売上の伸び・3年・5年の売上 CAGR・投下資本からの成長率・Damodaran の業種の値〈2025年版 21.6%〉）のどちらかで決まる。会社の見通しも、アナリストの予想も、どこにも入らない。
2. 見通しが下がっても動くのは、**次の決算書類（10-Q・10-K）が Layer3 に入って、直近12か月の売上の伸びが変わったとき**だけ。それも日曜の取り込み待ち（`EARNINGS_REFLECTION_LAG_STEP0.md`）で、見通しの引き下げが数字に出るのは、さらに1〜2四半期後。
3. INTU は成長率が設定の固定値（12.77%）で、10月12日から11月23日まで**1文字も動いていない**。会社の見通しは今年度 9〜10% → 8〜9%（BACKLOG の記載。検索では 8月の初回が 9〜10%、11月の Q1 では 8〜9%〈Mailchimpの売却を除く〉と読める）、TANUKI は 12.77% のまま。
4. 案は、**まず表示（印）にとどめる**ことを勧める（案1・案2）。理論株価に入れる案3は、決定(c)・FCF-OUTLIER-QUAL-1 の原則と合わず、今は勧めない。

## 4. 案

### 案1（勧める）: 予想の改定と成長率の差を、印で出す（表示だけ）

- Market Data Weekly で `revenue_estimate`・`eps_trend`・`eps_revisions` を82銘柄だけ取り、`attributes/{T}.json` に（`estimates` として）保存する。
- 印は2つ（表示だけ。理論株価・判定・stage は変えない。method_change にも登録しない）:
  - **成長率の差**: TANUKI の `phase1_growth` − アナリストの売上の伸び（今年度・来年度の高いほう）が X pt 以上なら「成長率の前提が予想より高い（TANUKI 12.8% ／予想 8.0〜8.2%）」。例: INTU +4.8pt、CRM +2.8pt、NOW −0.9pt（来年度は +2.6pt）。
  - **予想の引き下げ**: 今年度の予想EPSの90日前比が −10% 以下（または30日前比 −5% 以下）なら「アナリストが予想を下げている（90日で −13.8%）」。INTU が当たり、CRM・NOW は当たらない。
- 出す場所: stock.html の見出し、TANUKI SCORE の行、report.txt（`Earnings_Pending` と同じ作り〈`common/` に判定を1か所〉）。取れない銘柄には印を付けず、report.txt に「予想が取れないため付けられません」と書く（決算の反映前の印と同じ）。
- 費用: 上の取得 +3回/銘柄（週1回）。実装は小〜中。更新は日曜なので、決算の直後〜次の日曜までは古い（決算の反映前の印と組み合わせて「決算後・予想は日曜に更新」と書く）。

### 案2: 会社の見通しを手で記録して、差を印にする（表示だけ）

- `config/company_reported_metrics.json` と同じ形で、会社の売上・EPS・営業利益率の見通し（出典つき）を保有・買い検討の銘柄だけ手で記録し、TANUKI の成長率との差を印にする（案1の「予想」を「会社の見通し」に置き換える）。
- 取得の追加は無い。一方、記録の手間（決算ごと）と記録漏れ（CHECK-61 の型の検知を足す）が要る。会社の見通しは1次情報（資料のページ）に出典を付けられ、非決定の抜き出しも要らない。
- 案1と併用できる（案1は全銘柄の目安、案2は保有・買い検討の確かな値）。

### 案3（今は勧めない）: 理論株価の成長率に入れる

- 例: 成長率 = min(今の成長率, アナリストの売上の伸び + α)。または今の成長率と予想を信頼度で混ぜる（`growth_sanity` の候補に「予想の売上の伸び」を足す）。
- 計算方法の変更なので、method_change・`tools/sim` の全銘柄の試算・scope が要る（STEP 0b）。
- **決定(c)・FCF-OUTLIER-QUAL-1 の原則との関係**: 決定(c)（BACKLOG の PARSER-LAYER3 の決定 2026-11-11）は「申告に無い値は無いまま、0で埋めない」。アナリストの予想は申告（SEC）の値ではなく、計算に入れると「申告に無い値で計算を埋める」ことに当たる。FCF-OUTLIER-QUAL-1 は「AI・規則での抜き出しは参考表示にとどめ、判定・理論株価の計算には入れない」（非決定の入力は計算に入れない）。予想は Yahoo が集めた値で再現できるが、Yahoo の集計の変更・アナリストの入れ替わりで動き、検算ができない。会社の見通し（案2）を計算に入れるなら、出典つきの手の記録で再現できるが、手の記録が無い銘柄との差（記録のある銘柄だけ下がる）を決める必要がある。
- 影響の大きさ: 上の3銘柄では、成長率を予想まで下げても上昇余地は +50% 超〜+90% 前後で判定が崩れる様子は無い（内挿の目安）。全銘柄の影響は計算していない。
